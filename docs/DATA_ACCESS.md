# Data and artefact access

This repository deliberately does not track raw datasets, processed `.npz`
datasets, checkpoints, or prediction dumps. Those files are either too large
for GitHub or should be obtained from their original public source.

## What is in GitHub

The GitHub repository contains:

- Source code, configs, and Slurm launchers.
- Manuscript sources and publication figures.
- Released CSV, JSON, and Markdown diagnostics.
- `results/manifest.json`, a provenance manifest for the paper run.
- Lightweight verification and figure-regeneration scripts.

It does not contain:

- `data/`
- `results/checkpoints/`
- `results/predictions/`
- Slurm logs or W&B telemetry

The verifier enforces this policy:

```bash
python scripts/verify_release.py
```

## Heavy artefact deposit

The Zenodo deposit is reserved for artefacts that are not suitable for GitHub
but are useful for independent reanalysis:

```text
checkpoints/
predictions/
MANIFEST.txt
README.md
```

Expected size: about 8 GB.

DOI: pending. Once the DOI is reserved, update:

- `README.md`
- `CITATION.cff`
- `PUBLICATION_MANIFEST.md`

To build the deposit from the production tree:

```bash
make zenodo-pack
```

To consume a deposited zip:

```bash
git clone https://github.com/Dyniel/flowgat-paper.git
cd flowgat-paper
unzip ../flowgat_paper_zenodo_<DATE>.zip -d results/
python scripts/verify_release.py
```

After extraction, these paths should exist:

```text
results/checkpoints/
results/predictions/
```

## Source datasets

The source datasets are not redistributed by this repository.

| Domain | Source | Local generated folders |
|---|---|---|
| VMR aortas | Vascular Model Repository, `https://www.vascularmodel.com` | `data/npz_withleak/`, `data/npz_noleak/`, `data/npz_leak_dir_only/`, `data/npz_leak_mag_only/` |
| Womersley pipe | Analytic generator in this repo | `data/npz_womersley*/` |
| Cosserat sweep | Analytic generator in this repo | `data/npz_cosserat_sweep*/` |
| U-bend CFD | Original `newCFD_dataset` distribution from polybox.ethz.ch | `data/npz_subend*/` |

Generation scripts:

```text
src/preprocess_vmr.py
src/make_npz_noleak.py
src/make_npz_womersley.py
src/make_npz_womersley_variants.py
src/make_npz_cosserat_sweep.py
src/make_npz_cosserat_sweep_variants.py
src/make_npz_subend.py
src/make_npz_subend_variants.py
```

Cluster wrappers:

```text
jobs/00_build_data.sh
jobs/06_build_decomp_data.sh
jobs/20_cosserat_sweep_pipeline.sh
jobs/23_subend_build_npz.sh
```

## Integrity manifests

GitHub-side:

```text
results/manifest.json
```

Zenodo-side:

```text
MANIFEST.txt
```

The GitHub verifier confirms that the release manifest is present and has the
expected variants and seeds. The Zenodo manifest is generated by
`.pack_zenodo.sh` using `sha256sum` over every deposited file.
